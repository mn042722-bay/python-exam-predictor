# Python Exam Predictor

現在はCSVデータを集計・分析するアプリ

## 概要

csvからデータを読み込んで設定した各項目のデータを集計して表示させています。
また新しくデータを追加する機能も実装しました。

## 主な機能

`data/scores.csv` から試験データを読み込みます。

そこから
- 最高点
- 最低点
- 平均点
- 合格回数
- 合格率
- 最新スコア
- 前回比
- 70点以上の模試
- 合格ラインまであと何点

のデータを参照して表示させています。
平均点、合格率は小数点第一位までの表記に統一しています。

また、新たに試験データを保存できるような機能も備わっています。
追加するデータの点数・勉強時間・苦手分野数に数値以外を入力した場合は、エラーメッセージを表示します。


## 実行方法

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python main.py
```
